# Current UI (Local Edition)

The primary application is `streamlit run platform_ui.py` and starts **without any login**. No API server, setup token, tenant ID or user account is required.

Use the sidebar: Overview → Jobs → CV Library → Match Lab → Candidate Profile → Reports & Insights.

For complete functionality, see [LOCAL_FEATURES_AND_USE_CASES.md](LOCAL_FEATURES_AND_USE_CASES.md). The earlier authenticated API remains archived in source for compatibility but its onboarding instructions do not apply to this local product.
